ADB server controls

If a device is stuck on "offline" or "waiting", restart the ADB server. This is the kill switch for the local adb daemon; it does not touch your phone.

Wireless debugging

Android 11+: on the phone, Developer options → Wireless debugging. Use Pair with the pairing ip:port and 6-digit code once, then Connect with the main ip:port shown on the Wireless debugging screen.

"waiting for device" almost always means the phone shows as unauthorized (tap Allow on the phone) or offline (Restart ADB). Each device below says exactly which.
