Install APK

One .apk, or a split bundle (.apks / .xapk / .apkm: only the APK entries inside are used). Max 400 MB. The file is uploaded to this computer's sentinel data dir, installed with adb install, then deleted.

ADB server controls

            
If a device is stuck on "offline" or "waiting", restart the ADB server. This is the kill switch for the local adb daemon; it does not touch your phone.
